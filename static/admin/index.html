📝 使用说明

  1. 生成URL: 点击"生成新的测试URL"为每个被试创建唯一链接
  2. 发送给被试: 将生成的URL发送给对应的被试

  4. 导出结果: 测试结束后导出所有实验数据进行分析
⚠️ Attention Check 自动回收机制：

当被试在 Attention Check 失败后，测试组会自动释放并立即返回可用池， 其他被试可以立即使用该测试组。
• 无需管理员手动操作
• "重新分配URL"按钮仅用于特殊情况或重新分配已完成的测试

⚠️ 重要: 每个URL只能分配给一个被试，确保实验数据的唯一性！
